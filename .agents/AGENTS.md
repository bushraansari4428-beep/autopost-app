# Project Deployment Guidelines

- **Online Live Deployment**: The user always accesses and tests the application online at `https://autopost-app-one.vercel.app` (Frontend on Vercel, Backend on Render `https://autopost-app-1.onrender.com`).
- **Auto Commit & Push Requirement**: After making and verifying any code fix or feature addition, ALWAYS commit and push the changes to GitHub (`git push origin main`) so Vercel and Render auto-deploy the updates immediately.
